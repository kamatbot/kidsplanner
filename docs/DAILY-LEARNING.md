# Daily learning

Daily 3 groups News, Quote and Word. Brain Teaser / Puzzle has a separate
section and completion status. Existing `daily5` API and storage names remain
for compatibility; rewards retain their established activity keys.

Local Innovation requires positive innovation evidence and rejects mature
subjects in all supplied feed text before display truncation. Cached stories
retain the same screening decision. If no eligible story is available, the
slot stays empty. Screening covers supplied publisher feed text, not the
contents of every linked page.

Starting Monday 2026-09-21, quotes follow a Monday-based virtue theme:
integrity, collaboration, creativity and kindness. Original quotes are
attributed to Fam ETC. Vocabulary uses a weekly root and a different word each
day: Monday root/anchor, Tuesday connotation plus grammar, Wednesday synonyms,
Thursday antonym/prefix contrast, Friday academic register, and weekend review.
The authored curriculum contains 28 roots and 196 distinct words, then repeats
as a review cycle. Historical editions remain stable and the six-calendar-month
word freshness rule remains required.

The separate challenge uses existing brain teasers on Monday/Tuesday,
Sudoku plus mental math on Wednesday, source-linked news data analysis on
Thursday, original digital-SAT-style practice on Friday, and a vocabulary/news/
trivia crossword on weekends. Thursday datasets are explicitly dated practice
from primary sources; Friday questions are not College Board questions.
The initial data and SAT question banks each rotate through four reviewed items.
Weekend puzzles disclose a vocabulary/trivia fallback when no eligible news
is available, or an unavailable state when the bounded grid search cannot fit.

Updated clients request `schedule=weekly` on the puzzle endpoint. Older native
clients retain supported Sudoku/crossword payloads until their binary is updated.
Account/day/content identity scopes saved challenge progress. Wednesday requires
both components; editing or clearing a solved answer retracts completion.

Path Odds is removed from visible web/native dashboards. Its backend is retained
for future work. Native source changes require separate native release gates;
a web deployment does not distribute an iOS update.
